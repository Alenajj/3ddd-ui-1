# Типографика

Обновлено 01.10.2026 по таблице на листе «Текст» в Figma (страница кита).

Шрифт Roboto, начертания 400 / 500 / 700. Все тексты — только стилями ниже, размер и межстрочный интервал вручную не задаём. Цвет текста задаётся токенами `color/text/*`, а не стилем.

## Правила
1. display и heading/xl — адаптивные: на мобилке размер уменьшается сам (коллекция Responsive). Отдельно брать «стиль на ступень меньше» для телефона не нужно. heading/md на мобилке не меняется.
2. heading/xl — заголовок контента (пост блога, работа в галерее), один на страницу. heading/md — заголовок страницы со списком (блоги, галерея, модели), заголовок секции, попапа, модалки и пустого состояния. heading/sm — малые заголовки: группа полей, подзаголовок в карточке.
3. body — читаемый текст: описания, статьи, комментарии. label — короткие подписи интерактивных элементов: кнопки, вкладки, пункты меню, заголовки и подписи полей. caption — мелкие пояснения и мета.
4. Выделение внутри абзаца — body/md-strong (Medium), а не ручное «жирное».
5. caption/sm (10 px) — только короткие метки вроде PRO / FREE, не для предложений.
