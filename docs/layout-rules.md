Согласовано 01.10.2026. Источник: замеры 3ddd.ru и новой главной 3dsky.org.
В Figma: секция «Правила отступов и резиновой раскладки» на странице кита.

Разделы «Работа», «Форум», «Блог» не учитываем — они будут переделываться.

## Как тянется страница
Сайт уходит от Bootstrap к резиновым страницам. Образец — главная https://3dsky.org/.

1. **Секция** — полоса во всю ширину экрана с полями 12 слева и справа (`space/12`). Фон секции может идти от края до края.
2. **Контент** внутри секции: `width: 100%; max-width: 1320px; margin: 0 auto`. На экранах шире 1344 контент перестаёт расти и стоит по центру: пустые поля слева и справа растут поровну (на 1920 — примерно по 290 с каждой стороны). Фон секции при этом продолжает тянуться во всю ширину экрана.
3. **Сетки** — CSS Grid из равных колонок (`1fr`) с промежутком 24 (`space/24`). Ширина карточек тянется сама: при 6 колонках от 157 (экран 1100) до 200 (экран 1440). Это диапазон Model Card / Fluid — 156–204.
4. **Брейкпоинты меняют только количество колонок и раскладку блоков**, а не ширины:
   - сетка карточек моделей: 6 колонок → 4 ниже 992 → 2 ниже 768;
   - карточки галереи: 4 → 1 на телефоне.
5. **Сложные блоки** раскладываются по именованным зонам (`grid-template-areas`) и перестраиваются: 3 зоны в ряд от 1200 → 2 ряда на планшете → один столбец на телефоне.
6. **Bootstrap-сетку** (`row` / `col-*`) в новых страницах не используем.
7. **Макеты в Figma** делаем только для тех брейкпоинтов, на которых что-то меняется или перестраивается: меняется число колонок, блоки встают в столбец, прячется сайдбар и т. п. На макете подписываем, что именно изменилось. Обёртка контента: auto layout, ширина FILL, max width 1320; карточки — FILL.

8. **Ширина текста ограничена:** текстовая колонка не шире 756 (`size/text-max`), даже если контент 1320. Пример — карточка блога: картинка слева, текст справа до 756.
9. **Ряды чипсов и фильтров:** на компьютере переносятся на новую строку (промежуток 16 по горизонтали, 8 по вертикали). На телефоне — одна строка с горизонтальной прокруткой, строка заходит под поля до края экрана. Пример — категории блога 3dsky.
10. **Карточки, у которых меняется раскладка,** рисуем на тех брейкпоинтах, где она меняется. Пример — карточка блога: выше 768 картинка слева (16:9), ниже 768 картинка сверху во всю ширину, текст под ней через 12.

Пример CSS:
```css
.section { padding-inline: var(--space-12); }
.section__content { width: 100%; max-width: 1320px; margin-inline: auto; }
.cards-grid { display: grid; grid-template-columns: repeat(6, 1fr); gap: var(--space-48) var(--space-24); }
@media (max-width: 991.98px) { .cards-grid { grid-template-columns: repeat(4, 1fr); } }
@media (max-width: 767.98px) { .cards-grid { grid-template-columns: repeat(2, 1fr); } }
```

## Поверхности и скругления
| Уровень | Фон | Скругление | Тень |
|---|---|---|---|
| Страница | `bg/page`; `bg/section` — полоса во всю ширину для выделения секции | — | — |
| Карточка / блок | `surface/default` | `radius/16` (и на мобилке). Превью картинок — `radius/4`. Баннер — `radius/24` (Mobile `radius/12`) | нет |
| Плашка внутри карточки | `surface/subtle` | `radius/8` | — |
| Всплывающее (меню, дропдаун) | `surface/raised` | `radius/8` | `shadow/md` |
| Попап | `surface/raised` | `radius/24` (Mobile — во весь экран, без скругления) | нет, затемнение `overlay/scrim` |

### Концентрические скругления
Радиус внутреннего элемента = радиус внешнего − отступ между ними: **R внутр = R внеш − P**.
- Пример: карточка `radius/16`, отступ до картинки `space/4` → у картинки 16 − 4 = 12 (`radius/12`). Контуры идут параллельно и не режут глаз.
- Ошибка: одинаковый радиус у внешнего и внутреннего блока — рамки визуально расходятся и выглядят «грязно».
- Результат округляем до ближайшего токена `radius/*`. Если отступ больше или равен внешнему радиусу (R − P ≤ 0), формула не работает — внутренний элемент берёт свой обычный радиус (например, Menu Item `radius/8` внутри дропдауна).

**Попап** (модалок на сайте нет): компоненты Popup / Header, Popup / Body, Popup / No Header. Desktop — по центру на затемнении, отступы `space/48`, крестик Close Button 24. Mobile — во весь экран, отступы `space/24`, крестик Close Button 44.

## Формы
- Между полями формы — `space/32`, заголовок поля → поле — `space/8`, подпись поля стоит абсолютом (см. component-rules.md).
- Между кнопками — `space/8`. Группа кнопок под формой — `space/24` от последнего поля.

## Колонки страниц
- Каталог: фильтры 196 + 24 + контент.
- Страница модели: 856 + 24 + 416. На телефоне — одна колонка.

## Общие правила
1. Отступы — только из шкалы space: 0, 2, 4, 6, 8, 10, 12, 16, 20, 24, 32, 48, 60, 72, 80, 96.
2. Значения вне шкалы приводим к ближайшему: 18 → 16, 34 → 32.
3. Под заголовком страницы (H1) — 48, на телефоне 24. Под заголовком секции (H2) — 24. Разные значения под H2 на главной 3dsky (20 / 32 / 36 / 48) — отклонение, привести к 24.
6. Текстовая колонка — не шире 756 (`size/text-max`).
4. Между секциями — 80.
5. От шапки до контента 24, на главной 48.
