# Правила для компонентов

Согласовано 01.10.2026. Figma: «Кит для ии 2026», страница кита.

## Анимация переходов состояний (с 07.10.2026)
Правило для всех интерактивных элементов: кнопок, полей, пунктов меню, тегов, флажков, переключателей, карточек, подсказок и меню. Figma: секция «Анимация состояний», коллекция переменных Motion.
- **Появление — 0,2 с, ease-out:** переход в Hover, Active, Focus, выбранное состояние; открытие подсказки, меню, попапа.
- **Пропадание — 0,25 с, ease-out:** возврат в Default; закрытие подсказки, меню, попапа.
- Анимируются только цвета, рамки, тени и прозрачность. Размеры и положение элементов при смене состояния не меняются.
- Токены: `motion/duration/in` = 200 мс, `motion/duration/out` = 250 мс, `motion/easing/out` = ease-out. В CSS — `--motion-duration-in`, `--motion-duration-out`, `--motion-easing-out`.
- В CSS: у элемента в обычном состоянии `transition-duration: var(--motion-duration-out)`, а в `:hover`, `:active` и выбранном (`aria-pressed`, `aria-current`, `:checked`) — `var(--motion-duration-in)`. Браузер берёт время из того состояния, в которое переходит элемент, поэтому вход — 0,2 с, выход — 0,25 с.
- В прототипе Figma: Mouse enter → Hover (Smart animate, Ease out, 200 ms), Mouse leave → обратно (Smart animate, Ease out, 250 ms). Клик в любое состояние кроме Default — 200 ms, в Default — 250 ms. «While hovering» не используем: у него одно время на вход и выход.
- Если у пользователя включено «Уменьшить движение» (`prefers-reduced-motion`), переходы мгновенные — это уже в токенах.

## Крестик: кнопка или иконка
- **Close Button** — самостоятельная кнопка со своим ховером и подложкой: закрыть модалку, попап, очистить поле ввода. Размеры 24 (десктоп) и 44 (мобилка). Размер 20 удалён — слишком маленький для отдельной кнопки.
- **Icon / 20 / Close** — просто иконка, без ховера. Используем, когда компонент цельный и маленький: чипс, тег, токен в поле. Нажимается и подсвечивается весь компонент, а крестик меняет только цвет вместе с ним.
- В коде иконка рисуется `currentColor`, цвет задаёт родитель.

## Tag и Chip / Token
- **Tag** — метка или ссылка без крестика (теги модели, категории).
- **Chip / Token** — выбранное значение, которое можно удалить (токены в поле ввода, выбранные фильтры). Крестик — Icon / 20 / Close.
- Цвета **Chip / Token** (тёмный):

| Состояние | Фон | Текст | Иконки |
|---|---|---|---|
| Default | `fill/neutral-strong` | `text/inverse` | `icon/on-accent` |
| Hover | `fill/neutral-strong-hover` | `text/inverse` | `icon/on-accent` |
| Active | `fill/neutral-strong-active` | `text/inverse` | `icon/on-accent` |
| Disabled | `fill/disabled` | `text/disabled` | `icon/disabled` |

- Цвета **Tag**:

| Состояние | Фон | Текст | Иконки |
|---|---|---|---|
| Default | `fill/tag` | `text/muted` | звезда `icon/default`, крестик `icon/muted` |
| Hover | `fill/tag-hover` | `text/inverse` | `icon/on-accent` |
| Active | `fill/tag-active` | `text/inverse` | `icon/on-accent` |
| Disabled | `fill/disabled` | `text/disabled` | `icon/disabled` |

## Поля ввода
- **Input** — однострочное поле (`<input>`). Размеры Small (36, десктоп) и Mobile (44). Отступы 8/8.
- **Textarea** — многострочное поле (`<textarea>`), растёт по высоте. Состояния те же, что у Input. Снизу по желанию счётчик и кнопки.
- **Input / Password** — поле пароля. Small 36 / Mobile 44, отступы 8/8, цвета как у Input. Visibility: Hidden — пароль точками (●), иконка «глаз»; Shown — пароль текстом, иконка «глаз перечёркнут». Кнопка-глаз стоит абсолютом справа, зона нажатия 24 / 44.
- **Chips Field** — поле с выбором из списка и чипсами Chip / Token. Small 36 / Mobile 44, отступы 8/8. Focus — открытый список из Menu Item / Unified, стрелка вверх. Wrap=Yes — чипсы переносятся, поле растёт в высоту.
- **Заголовок и подпись** — отдельного компонента нет, это обычный текст со стилями:
  - **Заголовок:** стиль `label/md`. Два состояния: обычный — `text/default`, Disabled — `text/disabled`.
  - **Заголовок → поле:** 8 (`space/8`).
  - **Подпись:** стиль `label/md`. Обычная — `text/subtle`, ошибка — `text/danger`, успех — `text/success`, Disabled — `text/disabled`.
  - **Подпись стоит абсолютом:** 4 (`space/4`) от нижнего края поля, привязана к левому верхнему краю. Не влияет на высоту блока — когда появляется ошибка, соседние поля не сдвигаются.
  - **Подпись — в одну строку.** Если текста больше — сокращаем или выносим пояснение над полем.
  - **Между полями формы:** 32 (`space/32`) — в этот отступ помещается подпись (4 + 20) и остаётся 8 до следующего заголовка.
  - **В коде:** обёртка поля `position: relative`; подпись `position: absolute; top: 100%; margin-top: 4px`. Подпись связана с полем через `aria-describedby`, ошибка — `aria-invalid="true"`.
- Крестик очистки в Input — Close Button 24 (Small) / 44 (Mobile), позиционируется абсолютом, привязан к правому верхнему краю.
- Disabled у полей (Input, Textarea, Password, Chips Field): заливка остаётся базовой `fill/base` — серая заливка делает поле заметнее обычного. Меняются только рамка `border/disabled`, текст `text/disabled` и иконки `icon/disabled`.

## Карточка блога

## Комментарии
- **Comment** — State: Empty (плейсхолдер), Focus (курсор), Typing (текст + «Отправить»), Edit («Отменить» / «Сохранить»), Posted, Posted Hover (на десктопе «Редактировать» / «Удалить», на мобилке «⋮»). Level: Comment / Reply, Size: Desktop / Mobile. Части: Comment / Author, Comment / Badge (Role: Author / Buyer), Comment / Likes, Comment / Like, Comment / Replies Toggle.
- Текст комментария body/md `text/default`; имя автора и «2 ответа» label/lg `text/link`; «Ответить», «Редактировать», «Удалить» body/sm `text/link`; время и счётчики body/sm `text/subtle`; плейсхолдер `text/placeholder`.
- Поле ввода — линия снизу: в покое `border/strong`, при вводе `border/focus`.
- Бейджи: «Автор модели» — `surface/success` + `text/success`; «Покупатель» — `surface/warning` + `text/warning`.

## Тултип и уведомление
- **Tooltip** — подсказка у элемента при наведении. Style: Light (текст + «Подробнее»), Dark, Small (короткая метка).
- **Notification** — уведомление после действия (отдельного toast-компонента нет, уведомления выглядят как тултипы, но не привязаны к элементу). Type: Info — тёмное `fill/inverse-hover`, можно с действием («Изменить»); Error — красное `fill/danger`; Error Detailed — ошибка с кодом и пояснением (505). Текст `text/on-accent`.

## Скелетоны и пустые состояния
- **Скелетоны** отдельным компонентом не делаем — рисуем под каждую страницу, повторяя её элементы (картинка, строки текста). Цвет `fill/skeleton`, скругления как у элементов. Готовый пример — Blog Card, State=Loading.
- **Пустое состояние** в макетах можно оставлять пустым с пометкой «ручная доработка».

## Попап (на сайте модалок нет — только попапы)
- Компоненты: **Popup / Header** (шапка с заголовком в слоте Title и крестиком; Title=No — только крестик), **Popup / Body** (тело со слотом Content), **Popup / No Header** (попап без шапки: слот Content + крестик в углу).
- Size: Desktop / Mobile.
- Desktop: окно по центру на затемнении `overlay/scrim`, фон `surface/raised`, `radius/24`, отступы `space/48`, крестик Close Button 24.
- Mobile: во весь экран, отступы `space/24`, крестик Close Button 44.
- Тени нет.

## Пункт меню
- **Menu Item** — пункт выпадающего списка, попапа, бокового меню. Tone: Neutral (чёрный) / Accent (синий — категории в фильтрах каталога и избранного). Размеры Medium (36) и Large (44). Переключатели: чекбокс, иконка, стрелка, счётчик.
- **Menu Item / With Button** — пункт с кнопкой-иконкой справа. Отдельный компонент: у него свои отступы (справа 0, кнопка прижата к краю).

### Зона нажатия (Menu Item / Unified, с 07.10.2026)
- Размер компонента — только содержимое: иконка + текст + промежутки, отступов внутри нет.
- Зона нажатия и фон состояний — отдельный слой **Hit area**: прямоугольник с абсолютным положением, constraints Left & Right / Top & Bottom, выходит за содержимое на отрицательные отступы. Medium: 12 по бокам, 8 сверху и снизу (зона 36). Large: 16 и 12 (зона 44).
- Заливка Hover (`fill/ghost-hover`), Active (`fill/active`) и скругление `radius/8` стоят на Hit area. Clip content у компонента выключен.
- **Шаг между пунктами задаёт родительский список**, а не сам пункт. Чтобы текст стоял как при старом пункте с отступами: промежуток = старая высота пункта − 20 (Medium вплотную → 16, Large вплотную → 24, Large с промежутком 2 → 26), у списка поля 8 сверху и снизу (Large — 12) и 12 по бокам (Large — 16). Подсветки соседних пунктов при этом стыкуются без наложения.
- Вложенные уровни дерева сдвигаем отступом слева у вложенного списка (в мобильных фильтрах текст стоит на 16 / 28 / 52).
- В коде: размер кнопки по тексту, зона нажатия — псевдоэлемент `::before { content: ''; position: absolute; inset: -8px -12px; }` (у кнопки `position: relative`).
- Старый набор с отступами внутри пункта удалён 07.10.2026, все экземпляры перепривязаны (выпадающие списки Chips Field, пример на листе «Меню разделы», компонент Menu — там пункт обёрнут во фрейм с прежними полями 8/12, потому что список смешанный).

## Иконки
- **Где лежат:** все иконки кита — в секции «Иконки кита» на странице кита, по размерам. Имя «Icon / размер / Имя», имя по рисунку (Forum Filled, Forum Outline), размер — сторона квадратной рамки.
- **Устройство одноцветной иконки:** компонент с одним слоем **Union** (булево объединение рисунка; обводки переведены в контуры). Цвет стоит только на Union, на векторах внутри цвета нет. В экземпляре перекрашиваем слой Union — можно поставить любой цвет.
- **Цвет по умолчанию** — токен `icon/*`. Отдельных вариантов Hover / Active у иконки нет: цвет по состоянию задаёт компонент, в котором стоит иконка.
- **Замена иконки сохраняет цвет:** при замене в слоте Figma переносит цвет со слоя Union на слой Union новой иконки (совпадают имена слоёв). Поэтому все одноцветные иконки обязаны иметь ровно один слой с именем Union.
- **Залитая и контурная** версии — разные иконки (Forum Filled / Forum Outline), не две фигуры в одной рамке.
- **Без токенов, свои цвета:** медали, камни, цветные звёзды, огонь, флаги, бренды (V-Ray — `render/vray`, Corona — `render/corona`, Google), бейджи с цифрой. Их не перекрашиваем.
- **В коде** одноцветная иконка рисуется `currentColor`, цвет приходит от родителя.

## Цвет иконок в компонентах
- **Иконка в кнопке и в пункте меню — того же токена, что текст**, в каждом состоянии. Пример: Button / Primary — `text/on-accent`, Button / Secondary — `text/accent`, Disabled — `text/disabled`; Menu Item Accent — `text/accent` / `text/accent-hover` / `text/disabled`.
- Сделано во всех наборах секции Buttons (14 наборов) и в Menu Item / Unified. При замене звёздочки-примера на другую иконку цвет сохраняется.
