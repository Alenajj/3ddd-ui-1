export const Measured = ({ cls, children }) => {
  const ref = useRef(null);
  const [v, setV] = useState('');
  useEffect(() => {
    const read = () => {
      if (!ref.current) return;
      const cs = getComputedStyle(ref.current);
      setV(`${parseFloat(cs.fontSize)}/${parseFloat(cs.lineHeight)} · ${cs.fontWeight}`);
    };
    read();
    window.addEventListener('resize', read);
    return () => window.removeEventListener('resize', read);
  }, []);
  return (
    <div>
      <div ref={ref} className={cls} style={{ color: 'var(--color-text-default)', margin: 0 }}>{children}</div>
      <div className="text-caption-md" style={{ color: 'var(--color-text-subtle)', marginTop: 4 }}>сейчас на экране: {v}</div>
    </div>
  );
};

# Типографика

Текстовые стили — **не компоненты**, а глобальные классы и SCSS-миксины. Они собираются из Figma («Кит для ии 2026», текстовые стили) вместе с токенами. Шрифт Roboto, начертания 400 / 500 / 700.

Всего 15 стилей. Справа у каждого стиля — имя класса и миксина. Под образцом — реальный размер на экране: переключите размер экрана в панели сверху на «Телефон 375», и `display` с `heading-xl` уменьшатся сами.

## Как подключить

**Классы — на сайт один раз** (Angular, форум, /work — везде одинаково):

```html
<link rel="stylesheet" href="…/@3ddd/ui/src/styles/tokens.css">
<link rel="stylesheet" href="…/@3ddd/ui/src/styles/text-styles.css">
```

В Angular вместо `<link>` — в `angular.json` → `styles`:

```json
"styles": [
  "node_modules/@3ddd/ui/src/styles/tokens.css",
  "node_modules/@3ddd/ui/src/styles/text-styles.css"
]
```

**В разметке — тег по смыслу, вид классом:**

```html
<h1 class="text-heading-xl">Офис в рюкзаке</h1>
<h2 class="text-heading-md">Популярные модели</h2>
<p class="text-body-md">Отличная модель, всё открылось в Corona.</p>
```

**В стилях компонента — миксином** (файл миксинов сам CSS не создаёт, подключать можно где угодно):

```scss
@use '@3ddd/ui/src/styles/text-styles' as *;

.model-card__title {
  @include text-label-lg;
  color: var(--color-text-subtle);
}
```

## Правила

1. **Тег отдельно, стиль отдельно.** `h1`–`h6` выбираются по структуре страницы, внешний вид — классом. Заголовок попапа может быть `h2`, а на другой странице `h3` — выглядеть одинаково (`text-heading-md`).
2. **Никаких своих размеров.** В стилях не пишем `font-size`, `line-height`, `font-weight`, `font-family`, `font` — только класс или миксин. Это проверяется автоматически: `npm run lint:css`.
3. **Цвет — отдельно, токеном** `var(--color-text-*)`, а не стилем.
4. **Телефон — сам.** `display` и `heading-xl` уменьшаются ниже 768 через токены. «Стиль на ступень меньше» для мобилки не берём.
5. **Выделение в абзаце** — `text-body-md-strong`, а не `<b>` с ручным начертанием.
6. **`caption-sm` (10 px)** — только короткие метки PRO / FREE / beta, не для предложений.
